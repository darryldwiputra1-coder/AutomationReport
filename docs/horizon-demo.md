# Galaxy IMMA Horizon public demo

The Streamlit app displays a historical research example built from linked
public sources. It has no user accounts, worker processes, API keys, or writes
to a shared database.

Deploy on Streamlit Community Cloud with **app.py** as the entry point and
Python 3.12. In the app's sharing settings, select public access. To preview
locally, install requirements.txt and run `streamlit run app.py`.
